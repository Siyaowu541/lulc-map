# LULC reference data map

A static map linking 40 land-use / land-cover papers to their study areas.

Country shading and regional boxes are a literature index, not actual sample footprints. Access status is carried over from the source sheet. See the About the data panel for the coverage audit.

Map library: Leaflet 1.9.4 (BSD-2-Clause). Borders: Natural Earth (public domain).
